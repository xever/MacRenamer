# 界面
界面参考目录里的 “rename-初始界面.jpeg”
- 顶部是一些重命名的规则
- 中间是一些操作按钮，按钮右侧过滤是按已经拖入的文件名后缀进行。
- 底部是拖入的文件名和预览信息，效果可参考“rename-已经拖入文件.jpeg”
- 顶部菜单 文件下拉 有选择文件夹、选择文件……的菜单，选择文件允许多选
- 注意 文件拖入 或者选择后，所有的重命名操作，只是在下方展示预计结果，结果用红色，只有点击“执行改名”后才执行操作

## 顶部规则说明
- 忽略扩展名，默认勾选，勾上后，所有的选项有不对扩展名起作用
- 如果勾选了包含子文件夹，那么把文件夹拖入或者顶部菜单文件选择 文件夹的时候 会遍历子文件夹
- 如果勾选文件夹改名，那么底部文件信息也显示所有的文件夹
- 转换 下拉框 包含“不选择、扩展名大写、扩展名小写、全部大写、全部小写、首字母大写”等选项，并实现相应功能
- 随机 下拉框，包含“不选择、8位随机字母、8位随机数字、日期、日期+随机数、原名+日期” 注意日期使用文件的创建日期YYYYMMddHHmmss
- 插入、替换、替换为是输入框，下拉是显示上次使用的文本
- 勾选正则，表示前面的 替换、替换为 文本可以是perl格式的正则表达式。右侧下拉框默认出现一些日期、随机字符、纯数字的表达式
- 删除规则，左侧是单选框的（位置、定位符），位置是：删除可以从字符位置开始，按数字选择；定位符是：输入框，意思按用户输入的指定字符。右边出现“往箭头删除xx个字符”，箭头是左右箭头，xx是数字选择。箭头只有左右，每次点击换成另一个，如果是右，意思是按用户选择的位置或者字符 往右删除xx个字符，同理箭头往左是按用户选择的位置或者字符 往左删除xx个字符
- 增加一条规则：“序号”，作用是在文件名的最前或最后依次增加序号，如前面“001-，002-”，后面“-01，-02”。允许用户设置“起始值、增量、位数”，允许下拉选择“最前，最后”，允许输入分隔符。前面的“起始值、增量、位数” 都是数字，限定数字范围1-10，位数数字不够的前面补0，如限制位数0，比如001，002。分隔符限制输入长度5，禁止不合法的文件名字符输入。
- 
每一行的规则都可以上下拖动，按从上到下的规则顺序进行改名。
